# Mandarin HSK Learning Quiz

An interactive web-based application for practicing Mandarin Chinese at HSK Level 1. Built with vanilla HTML, CSS, and JavaScript, featuring multiple quiz modes, audio pronunciation, and a vocabulary reference.

## Features

### Quiz Modes
- **Character Recognition Quiz** — Identify Chinese characters from audio.
- **Reverse Quiz** — Match pinyin and English definitions to Chinese characters.
- **Sentence Quiz** — Practice with common HSK Level 1 sentences.
- **Sentence Builder** — Self-paced exploration of sentence structure and pronunciation.
- **Fill-in-the-Blank** — Grammar practice by filling missing characters in sentences.

### Learning Features
- **Audio Pronunciation** — Native pronunciation for all characters and sentences.
- **Progress Tracking** — Visual progress bar and scoring.
- **Vocabulary List** — Reference the HSK 1 vocabulary with audio.
- **Clean UI** — Accessible, responsive design with design tokens.

## Getting Started

### Requirements
- A modern web browser (Chrome, Firefox, Safari, or Edge);
- No installation or dependencies required.

### Running Online
Open the application directly in your browser:
https://talestoshiba.github.io/mandarin_hsk_learning/index.html

## Current Vocabulary

**HSK Level 1** — 150 characters minimum requirement. This app currently includes a curated subset:
- Common characters (的, 好, 很, 里, 吗, 你, 我, 想, 在, and 这);
- Essential sentences for beginners;
- Audio from Wikimedia Commons.
